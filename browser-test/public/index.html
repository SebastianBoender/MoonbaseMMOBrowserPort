Back for the memories

Remember wandering across the Moon, chatting with strangers and seeing how high the rocket pack could take you? This unofficial project brings the original Moon Base game to modern browsers, without the old Shockwave plug-in.

We made the browser port for nostalgic reasons. The original game, world and artwork belong to their respective creators. This is a community revival, with compatibility work still in progress.

The people who made it possible

Original game · Maid Marian

Moon Base was created by Maid Marian Entertainment. All credit for the original game goes to them. Thank you for the memories.

Browser port · The nostalgia project

We adapted the game for modern browsers using DirPlayer. This is an unofficial fan project, with no affiliation implied.

The Modern renderer is a patched DirPlayer build. Runtime source and build instructions · GPL license
